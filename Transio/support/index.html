Common questions

Why can't Transio open a local folder?

macOS may require you to choose that folder in the system picker. Use the folder selection control in Transio to grant access again.

Why does a server connection fail?

Check the protocol, host, port, username, and server permissions. SFTP commonly uses port 22; SMB commonly uses port 445.

Where can I see transfer errors?

Open the transfer queue or operation log. Settings lets you open or clear local failure records.

Can I resume every transfer?

Resume support depends on the protocol and server. WebDAV upload resume is currently unavailable; Transio may restart a transfer when safe resume is not possible.

Before sharing diagnostics

Failure records can include file names, source and destination paths, and error messages. Review and remove sensitive details before emailing logs or screenshots. Never send passwords or private keys.
